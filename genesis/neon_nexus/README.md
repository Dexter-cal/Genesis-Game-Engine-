# Neon Nexus: AI-First Demo

## Overview
Neon Nexus is a futuristic cyber-action demo built using the Genesis Engine. It showcases the engine's unique AI orchestration and real-time procedural content generation.

## Features
- **AI Agent Council**: 32 specialized agents managing everything from biome generation to NPC psychology.
- **Holo Behavior Layers**: Non-destructive behavior stacking for NPCs.
- **Dynamic Difficulty**: Real-time player behavioral modeling to adjust game tension.
- **NLP Command Console**: Manage the game world using natural language commands.

## Architecture
Built on the 56-crate modular Genesis architecture, utilizing:
- `genesis-ecs` for high-performance state management.
- `genesis-agents` for high-level intelligence.
- `genesis-ai` for low-level LLM and NLP routing.

## Development
The project structure in `genesis/neon_nexus` serves as a blueprint for AI-integrated game development.
